# 唐三浪清理

**唐三浪清理** —— 跨平台（Windows / macOS）的系统垃圾清理与磁盘空间管理工具。

完全离线运行：不联网、不上传任何数据；所有清理项都是内置白名单，只碰清单里的目录，不碰你的其他文件。

删除默认进回收站（macOS 为废纸篓），随时可还原；只有显式勾选「直接删除」才会绕过。

---

## 功能

- **安全清理**：内置白名单，分「系统 / 开发工具 / 浏览器 / 编辑器 / 聊天办公」等类别；绿色 = 一定安全（纯缓存 / 日志），黄色 = 建议先关闭对应软件再清。删除默认进回收站 / 废纸篓。
- **全程有反馈、可中断**：扫描 / 删除过程中实时显示进度与旋转指示，界面永不卡死；任何时刻都能【暂停 / 继续 / 停止】。删除走**文件级**进度，彻底解决旧版「处理大目录时像卡住」的问题。
- **大文件（只读）**：按体积从大到小列出用户数据区的大文件，系统目录 / 系统文件已硬排除；不提供任何删除入口。
- **已装软件（只读）**：Windows 读注册表卸载项、macOS 扫 `/Applications` 与 `~/Applications`，把各软件的真实体积列出来，回答「磁盘到底被谁占了」。
- **高级迁移（仅 Windows）**：把 C 盘的大目录整体搬到其他盘，原位置留一个 junction 联接，系统和软件完全无感知；含迁移账本（四层互备）、一键还原、整理归拢、未验证候选发现。
- **主题**：默认浅色，支持深色。

## 平台能力对照

| 能力 | Windows | macOS |
|---|---|---|
| 安全清理 | ✅ 37 条白名单 | ✅ 39 条白名单 |
| 删除去向 | 回收站 / 直接删除 | 废纸篓 / 直接删除 |
| 大文件（只读） | ✅ | ✅ |
| 已装软件（只读） | ✅ 注册表 | ✅ `/Applications` + `~/Applications` |
| 高级迁移 | ✅ 全量（robocopy + junction + 账本 + 还原 / 整理 / 候选） | ⛔ 不提供（macOS 无 C / D 分区概念，页面隐藏） |
| 管理员权限 | UAC 提权 | 系统级目录需 `sudo`，自动标注「需管理员」 |

## 下载安装

到 [Releases](../../releases) 页面下载对应平台的安装包：

- **Windows**：`*_x64-setup.exe`（双击安装）
- **macOS**：`*.dmg`（通用包，同时支持 Intel 与 Apple 芯片）

> macOS 首次打开若提示「无法验证开发者」，是因为安装包未做 Apple 公证。
> 把 app 拖进「应用程序」后执行一次下面这条命令即可（只需一次）：
>
> ```bash
> xattr -dr com.apple.quarantine "/Applications/唐三浪清理.app"
> ```

## 开发 / 构建

```bash
npm install          # 安装依赖
npm run tauri dev    # 开发调试
npm run tauri build  # 打包本机安装包
```

技术栈：Tauri 2 + Rust 后端 + Vue 3 / TypeScript / Vite 前端。

## 说明

- 本工具只做清理与只读盘点，不修改系统设置、不联网。
- Windows 专属能力（迁移、junction、注册表、UAC 提权）用 `#[cfg(windows)]` 隔离，macOS 隐藏对应入口。
